自然语言到 API 列表

步骤库用的是 steps.yaml。API 库只收录这些步骤的 action_handler。同一句话走三种方案，程序停在 API 列表，不发真实请求。步骤是否命中靠写死的关键词。

生成按钮要和 engine.js、app.js、styles.css 放在同一个文件夹里才会工作。只把这个网页另存到本地时，点击没有反应。请下载整个 nl2task 文件夹，解压后双击其中的 index.html。
