自然语言到 API 列表

步骤库用的是 steps.yaml。API 库只收录这些步骤的 action_handler。点生成后，三种方案各向模型发一次请求。程序只保留库里有的名称，并停在 API 列表。

模型调用由本机服务转发。在 nl2task 目录先设置 LLM_API_KEY 和 LLM_BASE_URL，再执行 node server.js，然后打开 http://127.0.0.1:8765/ 。只双击这个网页不会发出请求。密钥放在环境变量里，不要写进文件。
